יש לי עוזרת בשם Nano — על שם NanoClaw, הטכנולוגיה שהיא רצה עליה. הדרך הכי פשוטה לתאר אותה: מוח שני שלא שוכח כלום. היא זוכרת הכול, לרוחב כל השיחות: לוחות הזמנים של הילדים, מה בת הזוג שלי ביקשה שאטפל בו, איזה רופא אמר מה, מי חייב למי, הדבר ההוא שהזכרתי לפני חודש — כך שאני אף פעם לא צריך להסביר את עצמי מחדש.

והיא שייכת לכל הבית, לא רק לי. היא חיה בקבוצת הוואטסאפ המשפחתית שלנו, כך שאני ובת הזוג שלי מדברים עם אותה עוזרת — מוח משותף אחד למשק הבית, במקום שני אנשים שכל אחד מנסה להחזיק הכול בראש. היא מוסרת לה דבר אחד, אני מוסר לה דבר אחר, והכול נוחת במקום אחד; שום דבר לא נופל בין הכיסאות. זה המשפחתי שבראש מטה משפחתי — זו לא תוספת, זו חצי מהסיבה שבניתי אותה.

והיא גם פועלת. אני אומר "תזמיני את הפיקלבול של אחת" וזה נסגר. היא שולחת הודעות לספקים, מוסיפה אירועים ליומנים שלנו, ורצה ברקע — תדריך בוקר, מעקב ימי הולדת, התראות על מיילים מבית הספר, ורשימה מתגלגלת של הבקשות של בת הזוג שלי כדי ששום דבר לא ייפול (אני קורא לזה רשימת הנודניק). כשאני צריך שיחפשו לי משהו, היא מוצאת את זה בזמן אמת. היא אפילו תרים טלפון ותתקשר — בקול אמיתי — כדי להזמין שולחן או לאשר תור.

והנה למה זה משנה. יש לי עבודה תובענית, שלושה ילדים, והמון דברים שזזים בו־זמנית. מה ששוחק אותי זה לא ההחלטות הגדולות — אלה ארבעים הדברים הקטנים שאני אמור לזכור. Nano נושאת את העומס הזה כדי שאני אהיה נוכח בדברים שבאמת חשובים. זה לא קסם; זה זיכרון ממש טוב ועוד מערכת שרצה בשקט ברקע. אבל זה באמת שינה את הדרך שבה אני עובר את השבוע.

שום דבר מזה הוא לא הדגמה — זו המערכת היומיומית האמיתית שלי, שחיה בשרשור הוואטסאפ המשפחתי שלנו. אנשים לא מפסיקים לשאול איך זה עובד, אז הנה כל הבנייה, ממחשב ריק ועד לזה. כל שלב מפורק לפעולה הקטנה ביותר, ואתם אף פעם לא מקלידים פקודה. (הפרטים האישיים הוחלפו בפרטים גנריים.)

מה צריך: מחשב Mac או Linux (Windows עובד דרך WSL2) וכשעה של זמן. Claude Code — אפליקציית Mac רגילה — עושה את ההנדסה בפועל; אתם בעיקר תדברו איתה, בלי טרמינל.

⚡ קיצור דרך: המדריך הזה הוא גם פרומפט. הדביקו את כולו לתוך Claude Code ואמרו "תבנה לי את זה." היא תעבור על כל שלב שהיא יכולה לבצע לבד, ותעצור רק כשהיא באמת צריכה אתכם — התחברויות, סריקת QR אחת, כמה בחירות. צפו לשש עצירות בערך.

פרק 1

מה זה NanoClaw — ולמה אני סומך עליו

לא הייתי מחבר קופסה שחורה ללוגיסטיקה של המשפחה שלי. הסיבה שאני משתמש ב־NanoClaw היא שאני באמת מסוגל להבין אותו:

  • הוא קטן. תהליך מארח אחד וקומץ קבצים. אם אני רוצה לדעת איך משהו עובד, אני מבקש מ־Claude Code לעבור איתי על הקובץ הזה.
  • הוא לא ממציא את הסוכן מחדש. החלקים הקשים — המודל, החשיבה, הרצת הכלים — מועברים ל־Claude Agent SDK הרשמי של Anthropic, אותו מנוע שמפעיל את Claude Code. NanoClaw שומר לעצמו רק את הצנרת שהוא באמת צריך: ניתוב הודעות, קונטיינרים, זיכרון.
  • בלי חומרה מיוחדת. הוא רץ על ה־Mac או ה־Linux שכבר יש לכם — בלי Mac mini, בלי שרת ענן לשכור. לפטופ ישן יספיק.
  • הסוכנים רצים בקונטיינרים, לא מאחורי בקשות הרשאה. כל עוזרת רצה בתוך קונטיינר Linux משלה ורואה רק את התיקיות שחיברתי לה במפורש. "תני לה להריץ bash" זה בטוח, כי ה־bash רץ בתוך הקופסה, לא על הלפטופ שלי.
  • סודות אף פעם לא נכנסים לקונטיינר. מפתחות API וטוקנים של OAuth חיים בכספת מקומית (OneCLI). כשהסוכנת מבצעת קריאת API, הכספת מזריקה את הסוד האמיתי ברגע האחרון. הקונטיינר מעולם לא מחזיק סוד שמיש — כך שגם בתרחיש הגרוע ביותר, אין מה לגנוב מתוכו.

זו העסקה שרציתי: מסוגלת מספיק כדי לפעול בשמי, סגורה מספיק כדי שאישן טוב בלילה. ריפו ותיעוד: github.com/qwibitai/nanoclaw · docs.nanoclaw.dev.

פרק 2

התקנה — שלב אחר שלב

ב־Mac, Claude Code היא סתם אפליקציה — אתם אף פעם לא פותחים טרמינל. מתקינים אותה, מכוונים אותה לתיקייה ריקה, ומבקשים ממנה לעשות את השאר: היא בוחרת ומתקינה את סביבת הקונטיינרים המתאימה למחשב שלכם, משכפלת את NanoClaw, ומריצה את ההתקנה.

מקרא. יש רק שני מקומות שבהם אתם פועלים: בדפדפן (הורדה אחת — האפליקציה עצמה) ו→ Claude Code (כל השאר, פשוט בבקשה). ב־Mac אין בכלל שלב טרמינל.

1
התקינו את אפליקציית Claude Code

ב־Mac זו אפליקציית דסקטופ רגילה — פותחים אותה כמו Notes או Slack. הורידו מ־claude.ai/download והתקינו. (גם Linux עובד, דרך ה־CLI; ב־Windows הפעילו קודם WSL2 — wsl --install ב־PowerShell כמנהל — והריצו שם.)

2
בקשו מ־Claude Code להכין את המחשב

צרו תיקייה ריקה, פתחו בתוכה את Claude Code, ואמרו לה:

→ Claude Code
תתקיני NanoClaw על המחשב הזה. תבדקי את המערכת שלי ותתקיני כל מה שצריך — כולל סביבת הקונטיינרים המתאימה לכמות מקום הדיסק שיש לי — ואז תשכפלי את הריפו ותתחילי את ההתקנה המודרכת.

היא בודקת את מערכת ההפעלה ואת המקום הפנוי, ואז מתקינה ומגדירה סביבת קונטיינרים — ארגז החול שכל סוכנת רצה בתוכו. יש יותר מאפשרות אחת: Docker Desktop מלא על מחשב מרווח, או סביבה קלה יותר (Colima, OrbStack, או Apple Container המובנה של macOS) כשצפוף. אתם לא בוחרים — Claude Code בוחרת, לפי המחשב האמיתי שלכם.

למה לא פשוט "להתקין Docker"? Docker Desktop כבד. על המחשב שלי לא היה מקום בשבילו, אז Claude Code הרימה לי סביבה קלה יותר במקום — אותה תוצאה, שבריר מהנפח. בדיוק בגלל זה עדיף לתת לה להחליט במקום לעקוב אחרי פקודה קבועה.

3
ענו על ההתקנה המודרכת

שאלון קצר ואינטראקטיבי, בתוך אפליקציית Claude Code — בלי חלון טרמינל נפרד. שלושה דברים:

  1. איך להתחבר ל־Claude — מנוי Claude Pro/Max (מדביקים טוקן) או מפתח API של Anthropic.
  2. אילו תיקיות הסוכנת רשאית לראות — התחילו במינימום; תרחיבו אחר כך.
  3. הערוץ הראשון שלכם — Telegram, Discord, WhatsApp, או CLI מקומי. אם אתם רק רוצים לראות שזה עובד, בחרו CLI; נחבר וואטסאפ כמו שצריך בפרק 5.
4
חכו לבנייה הראשונה

היא מורידה ומרכיבה את דמות הסוכנת — כמה דקות. בסיום תראו סיכום הצלחה, ו־NanoClaw מתקין את עצמו כשירות רקע שעולה עם ההתחברות ומרים את עצמו מחדש אם הוא קורס.

5
אם משהו נתקע

אתם לא מנפים את זה בעצמכם — בשביל זה בנינו על Claude Code:

→ Claude Code
משהו לא עובד — תבדקי את הלוגים ותביני למה.

(הלוגים נמצאים ב־logs/nanoclaw.log.)

✅ עכשיו יש לכם עוזרת שרצה. כל מה שמכאן והלאה הוא הוספת יכולות — וכל אחת מהן היא אותה תנועה: פשוט לבקש.

פרק 3

להכיר את הסוכנת — הכלל היחיד שחשוב

בסיום ההתקנה תקבלו הודעת ברוכים־הבאים מהעוזרת שלכם. כברירת מחדל מילת ההפעלה היא @Andy. אני שיניתי את שלי. הנה איך, כי זה ההרגל הכי חשוב בכל המדריך הזה — פתחתי את Claude Code ואמרתי:

→ Claude Code
תשני את מילת ההפעלה ל־@Nano.

זהו — לא הרצתי פקודה, פשוט ביקשתי. ל־NanoClaw אין מסך הגדרות, ואין פקודות לשנן: אתם מתארים מה אתם רוצים ו־Claude Code בונה את זה. רוצים תשובות קצרות יותר? תגידו לה. ברכת בוקר מותאמת כשאתם אומרים "בוקר טוב"? תגידו לה. השינוי נדבק.

תחזיקו בזה, כי כל שלב שלמטה הוא אחת משתי אותן תנועות: → Claude Code כדי לבנות ולשנות את המערכת, ו־→ Nano כדי לקבוע איך היא מתנהגת ביום־יום.

פרק 4

והנה מה שהופך את זה למוח של משק בית ולא רק שלי: ברגע ש־Nano נמצאת בצ'אט המשפחתי, בת הזוג שלי מזינה את אותם קבצים. כשהשחייה עוברת ליום חמישי והיא מזכירה את זה שם, הדף של הילד מתעדכן — אף אחד לא צריך לחזור על זה בפניי, זה פשוט נכון בתדריך של מחר. הפסקתי להיות נקודת הכשל היחידה של עובדות משפחתיות.

שני כללים הופכים את הזיכרון לאמין — והם מתקנים את כשל מספר 1 של עוזרי AI:

  1. אין "שמרתי" בלי שמירה אמיתית. אסור לסוכנת לומר "סבבה, רשמתי!" אלא אם היא באמת כתבה את הקובץ באותו תור בדיוק. יש אפילו מנגנון גיבוי בצד המארח שתופס "שמרתי את זה" מזויף ומכריח אותה לבצע את הכתיבה באמת.
  2. כל כתיבה נרשמת ביומן, וזה מה שהופך את הזיכרון לניתן לחיפוש לאורך זמן ("מתי דיברנו לאחרונה על הברז הדולף?").

מעבר לזה, הוויקי מסדר את עצמו בשקט — רפלקציה לילית שתופסת דברים שהיה צריך לשמור, ועוד מעברי ניקיון ותקצור שבועיים שאתם לא רואים.

רשות: כוונו את Obsidian לתיקיית wiki/ ותוכלו לקרוא ולערוך את הכול כמו ארגז פתקים רגיל.

פרק 8

להפוך אותה ליוזמת — המתכונים

כל מה שעשינו עד כה הוא תגובתי — היא עונה כששואלים. התחושה של ראש מטה מגיעה מזה שהעוזרת פועלת לפני שביקשתם. זה שלושה דברים שעובדים ביחד:

  • משימות מתוזמנות = המתי (תדריך ב־07:30).
  • כללים בפרוזה בזיכרון שלה = האיך, מה, ובאיזה טון.
  • הוויקי = המה שהיא כבר יודעת (מי הבייביסיטר, איפה "המקום הרגיל").

אתם אף פעם לא נוגעים בתחביר של cron. התזמונים רצים באזור הזמן שלכם; חלק מהמשימות שקטות בכוונה בעוד שתזכורות שולחות הודעה; ומשימה יכולה להריץ בדיקה זעירה קודם ורק אז להעיר את העוזרת אם יש משהו ששווה לומר — כך שהיא עוקבת אחרי משהו כל שעה בלי להציף אתכם בימים שקטים.

פרק 10

לחיות עם זה — פרטיות ותחזוקה

לחבר AI לחיים של המשפחה שלכם זה חכם רק אם חשבתם על הקצוות. העמדה שאני מריץ:

  • בידוד כברירת מחדל — כל סוכנת היא קונטיינר שרואה רק את מה שחיברתי.
  • סודות נשארים מחוץ להישג יד — כל סוד מוזרק על ידי הכספת ברגע הבקשה; הקונטיינר אף פעם לא מחזיק מפתח שמיש.
  • שולחים לא מוכרים חסומים בשער — זר שהתווסף לקבוצה לא יכול לגרום לעוזרת לעשות כלום עד שאני מאשר.
  • פרטי נשאר פרטי — כלל קבוע לא להדליף הקשר מהצ'אט הפרטי לקבוצה המשפחתית; קבוצות שאינן משפחתיות נעולות מבחינת פרטיות.
  • יש דברים שהם לא מוחלט — אמרתי לה לסרב באופן גורף לבקשות שמכוונות לסודות (איפוסי סיסמה, קודי אימות דו־שלבי, מספרי כרטיס מלאים), בכל ניסוח שהן מגיעות.

התחזוקה קלה. השירות מרים את עצמו אם הוא קורס ועולה לבד כשמתחברים. כשאני רוצה לבדוק מה שלומו — או לשנות משהו — אני פשוט מבקש:

→ Claude Code
תפעילי מחדש את NanoClaw, ותגידי לי אם משהו נראה חריג בלוגים.

זה כל הסיפור: זיכרון משותף, הצ'אט שהמשפחה שלכם כבר רצה עליו, כמה כלים, והאומץ לתת לה לפעול לבד. תתחילו מההתקנה ומהוויקי, תעבירו אותה לצ'אט המשפחתי, ואז תוסיפו מתכון יוזם אחד ותחיו איתו שבוע — תוך כמה ימים תדעו איזה חלק הבית שלכם רוצה הבא בתור.

ואתם אף פעם לא נעולים על הבחירות שלי. לא אוהבים איך היא מנסחת את התדריך? תגידו לה. רוצים שהיא תנדנד לכם על חוט דנטלי? תגידו לה. זה ראש המטה של המשפחה שלכם — בנוי על בסיס קוד קטן מספיק שאתם, ו־Claude Code, יכולים לעקם אותו לצורה המדויקת של החיים שלכם ביחד.
